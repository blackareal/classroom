⚙️ ตั้งค่า Google Sheet

เปิดไฟล์ mastery_m5.html แล้วแก้ค่า SHEET_ID ด้านบนของ script:

  1. สร้าง Google Sheet → คอลัมน์ A: no คอลัมน์ B: step
  2. กรอกข้อมูลนักเรียน 31 คน (no 1–31, step เริ่มที่ 0)
  3. แชร์ Sheet → "Anyone with link can view"
  4. คัดลอก ID จาก URL เช่น docs.google.com/spreadsheets/d/ID_อยู่ตรงนี้/edit
  5. วาง ID ในตัวแปร SHEET_ID ในไฟล์ HTML
