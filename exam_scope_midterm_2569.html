ค21101 คณิตศาสตร์พื้นฐาน 1 — ชั้น ม.1/1

สอบกลางภาค: 20–24 กรกฎาคม 2569  |  คาบที่เหลือสัปดาห์นี้: อ.14 (1 คาบ) + พ.15 (1 คาบ)
⚠ ปรับขอบเขต — ตัดเลขยกกำลังออก (ยังไม่ได้สอน)
✓ สอนแล้ว → จะสอนสัปดาห์นี้
หน่วยที่ 1: จำนวนเต็ม
  • จำนวนเต็มบวก จำนวนเต็มลบ ศูนย์ และเส้นจำนวน
  • การบวกและการลบจำนวนเต็ม
  • การคูณและการหารจำนวนเต็ม
  • สมบัติของจำนวนเต็ม (สลับที่ เปลี่ยนหมู่ แจกแจง)
  • โจทย์ปัญหาจำนวนเต็มในชีวิตจริง
หน่วยที่ 2: การสร้างเรขาคณิตเบื้องต้น
  • เครื่องมือ: วงเวียน ไม้ฉาก ไม้โปรแทรกเตอร์
  • ส่วนของเส้นตรงและการแบ่งครึ่งส่วนของเส้นตรง
  • มุมชนิดต่างๆ (แหลม ฉาก ป้าน กลับ ตรง)
  • การสร้างมุม 60° และ 90°
  • การแบ่งครึ่งมุม (อ.14)
  • เส้นขนานและเส้นตั้งฉาก (ถ้าเวลาเอื้ออำนวย)
❌ ไม่รวมในการสอบกลางภาค เลขยกกำลัง — ยังไม่ได้สอน จะเรียนในภาคเรียนหลังกลางภาค
📅 แผนคาบที่เหลือ อ.14 ก.ค. — การแบ่งครึ่งมุม (ต่อเรขาคณิต)
พ.15 ก.ค. — ทบทวนรวม + แจ้งขอบเขตข้อสอบให้นักเรียนทราบ

ค22101 คณิตศาสตร์พื้นฐาน 3 — ชั้น ม.2/1

สอบกลางภาค: 20–24 กรกฎาคม 2569  |  คาบที่เหลือ: อ.14 (1 คาบ) + พฤ.16 (1 คาบ)
⚠ ปรับขอบเขต — ตัดระบบสมการออก (ยังไม่ได้สอน)
✓ สอนแล้ว → จะสอนสัปดาห์นี้
หน่วยที่ 1: พีชคณิต
  • นิพจน์พีชคณิต ตัวแปร สัมประสิทธิ์
  • พจน์คล้าย การรวมพจน์
  • การบวก ลบ คูณ หาร พหุนาม
  • แฟกเตอร์ (หน้าร่วมมาก)
  • โจทย์ปัญหาพีชคณิต
หน่วยที่ 2: อัตราส่วนและสัดส่วน
  • อัตราส่วน a:b อัตราส่วนที่เท่ากัน การลดรูป
  • สัดส่วน: ความหมาย สมบัติขั้วคูณ
  • สัดส่วนโดยตรงและสัดส่วนผกผัน
หน่วยที่ 3: ร้อยละ
  • ความหมายร้อยละ การแปลง ร้อยละ ↔ ทศนิยม ↔ เศษส่วน
  • การคำนวณร้อยละ โจทย์กำไร-ขาดทุน ดอกเบี้ย (อ.14)
  • ทบทวนรวม (พฤ.16)
❌ ไม่รวมในการสอบกลางภาค ระบบสมการเชิงเส้นสองตัวแปร — ยังไม่ได้สอน จะเรียนหลังกลางภาค
📅 แผนคาบที่เหลือ อ.14 ก.ค. — ร้อยละ (ต่อ): การคำนวณ โจทย์กำไร-ขาดทุน
พฤ.16 ก.ค. — ทบทวนรวม + แจ้งขอบเขตข้อสอบให้นักเรียนทราบ

ค31101 คณิตศาสตร์พื้นฐาน 1 — ชั้น ม.4

สอบกลางภาค: 21–25 กรกฎาคม 2569  |  พ.15 ก.ค. = ทดสอบย่อย
✅ เนื้อหาครบสมบูรณ์ — พร้อมสอบ
หน่วย: เซต
  • ความหมายของเซต สัญลักษณ์ (∈, ∉, ⊂, ⊆, ⊄)
  • เซตจำกัด เซตอนันต์ เซตว่าง (∅)
  • เซตเท่ากัน เซตย่อย เซตที่เท่ากัน
  • การดำเนินการ: ยูเนียน (∪), อินเตอร์เซกชัน (∩), ผลต่าง (−), คอมพลีเมนต์ (A′)
  • จำนวนสมาชิก n(A∪B) = n(A) + n(B) − n(A∩B)
  • เพาเวอร์เซต P(A): จำนวนสมาชิก = 2ⁿ เซต
  • ไดอะแกรมเวนน์-ออยเลอร์
📅 แผนคาบที่เหลือ พ.15 ก.ค. — ทดสอบย่อยครอบคลุมทุกหัวข้อเซต ก่อนสอบกลางภาคจริง

ค32201 คณิตศาสตร์เพิ่มเติม 3 — ชั้น ม.5

สอบกลางภาค: 20–21 กรกฎาคม 2569  |  พฤ.16 = กฎไซน์, ศ.17 = ทบทวนรวม
✅ จบทันพอดี — เหลือ 2 คาบ 2 หัวข้อ
✓ สอนแล้ว → จะสอนสัปดาห์นี้
หน่วย: ตรีโกณมิติ
  • เอกลักษณ์ฟังก์ชันตรีโกณมิติ (sin²θ + cos²θ = 1, tan, cot, sec, csc)
  • สมการตรีโกณมิติ: sin x = k, cos x = k, tan x = k ใน [0, 2π]
  • กฎโคไซน์: a² = b² + c² − 2bc·cos A (หาด้านและหามุม)
  • กฎไซน์: a/sin A = b/sin B = c/sin C (พฤ.16)
  • ทบทวนรวมตรีโกณมิติทั้งหมด (ศ.17)
📅 แผนคาบที่เหลือ พฤ.16 ก.ค. — กฎไซน์: หาด้าน หามุม โจทย์ประยุกต์
ศ.17 ก.ค. — ทบทวนรวมทุกหัวข้อ + ซักถาม เตรียมสอบ

ค33101 คณิตศาสตร์พื้นฐาน 5 — ชั้น ม.6

สอบกลางภาค: 20–24 กรกฎาคม 2569  |  ศ.17 ก.ค. = ทดสอบย่อย
✅ เนื้อหาครบสมบูรณ์ — พร้อมสอบ
หน่วย: สถิติ
  • ค่ากลางของข้อมูล: ค่าเฉลี่ยเลขคณิต (μ = Σxᵢ / N)
  • มัธยฐาน (Median) — ค่ากลางเมื่อเรียงข้อมูล
  • ฐานนิยม (Mode) — ข้อมูลที่ปรากฏบ่อยสุด
  • ส่วนเบี่ยงเบนมาตรฐาน σ = √(Σ(xᵢ − μ)² / N)
  • การแปลความหมาย S.D. (S.D. น้อย = ข้อมูลกระจุกตัว)
  • สถิติเชิงอนุมาน: ประชากร ตัวอย่าง การสุ่มตัวอย่าง
📅 แผนคาบที่เหลือ ศ.17 ก.ค. — ทดสอบย่อยครอบคลุมทุกหัวข้อสถิติ ก่อนสอบกลางภาคจริง

ค33201 คณิตศาสตร์เพิ่มเติม 5 — ชั้น ม.6

สอบกลางภาค: 20–24 กรกฎาคม 2569  |  พ.15 + พฤ.16 = ทบทวน (ก้าวหน้า timeline 1 สัปดาห์)
✅ เนื้อหาครบ — มีเวลาทบทวนเพิ่ม
หน่วยที่ 1: ลำดับ
  • ลำดับเลขคณิต: aₙ = a₁ + (n−1)d
  • ลำดับเรขาคณิต: aₙ = a₁ · rⁿ⁻¹
  • ลำดับแบบอื่น (กำหนดด้วยนิยาม aₙ)
หน่วยที่ 2: อนุกรม
  • อนุกรมเลขคณิต: Sₙ = n/2 · (a₁ + aₙ)
  • อนุกรมเรขาคณิต: Sₙ = a₁(1 − rⁿ) / (1 − r)
  • อนุกรมอนันต์: S∞ = a₁ / (1 − r) เมื่อ |r| < 1
หน่วยที่ 3: ลิมิตเบื้องต้น
  • ความหมายของลิมิต: lim f(x) สัญชาตญาณ
  • ลิมิตพื้นฐาน (lim c, lim x, lim xⁿ)
  • กฎการหาลิมิต 7 กฎ (บวก ลบ คูณ หาร ยกกำลัง ค่าคงที่ รากที่ n)
📅 แผนคาบที่เหลือ พ.15 ก.ค. — ลิมิตที่ไม่มีอยู่จริง / one-sided limits (บทเสริม)
พฤ.16 ก.ค. — ทบทวนรวม ลำดับ อนุกรม ลิมิต เตรียมสอบกลางภาค
