อะตอม = ทรงกลมทึบตัน ไม่มีอะไรข้างใน

🧪 ทดลอง: กฎสัดส่วนคงที่

สารเคมีรวมตัวด้วย "อัตราส่วนที่ลงตัวเป๊ะ" เพราะอะตอมมีขนาดแน่นอน

💧 น้ำ (H₂O)

💡 แนวคิดหลัก

สารทุกชนิดประกอบด้วยอนุภาคที่เล็กที่สุดจนตัดแบ่งไม่ได้อีก เรียกว่า "อะตอม" (Atom) — ทรงกลมตัน ทึบ ไม่มีอะไรข้างใน

📏 คุณสมบัติ

• อะตอมไม่สามารถสร้างหรือทำลายได้
• อะตอมของธาตุชนิดเดียวกันเหมือนกันทุกประการ
• อะตอมต่างธาตุมีมวลต่างกัน

✅ จุดแข็ง

อธิบายกฎสัดส่วนคงที่และกฎสัดส่วนพหุคูณได้ — เป็นรากฐานของเคมีสมัยใหม่!

⚡ ทดลอง: หลอดรังสีแคโทด (Cathode Ray Tube)

รังสีเบนเข้าหาขั้วบวกของแม่เหล็ก → ต้องมีประจุลบซ่อนอยู่!

💡 การค้นพบสำคัญ

ค้นพบ อิเล็กตรอน (Electron) — อนุภาคประจุลบที่มีขนาดเล็กกว่าอะตอมถึง 2,000 เท่า!

🍩 โมเดลขนมปังลูกเกด

อะตอม = เนื้อบวก (แป้ง) กระจายอยู่ทั่วไป + อิเล็กตรอน (ลูกเกด) ฝังอยู่ประปราย เพื่อรักษาสมดุล

📐 ขนาด

อิเล็กตรอนเล็กกว่าอะตอมมาก มวลน้อยมาก แต่มีประจุลบที่ชัดเจน → ทำลายทฤษฎีดอลตันที่บอกว่าอะตอมตัน!

ระบบสุริยะจิ๋ว — นิวเคลียสตรงกลาง อิเล็กตรอนวิ่งรอบ

🎯 ทดลอง: ยิงอนุภาคแอลฟาใส่แผ่นทองคำ

ทุก 20,000 ตัว จะมี 1 ตัวที่สะท้อนกลับ!

ยิงไป: 0 | ผ่านทะลุ: 0 | สะท้อน: 0

💡 การค้นพบ

ค้นพบ นิวเคลียส — ก้อนประจุบวกที่หนาแน่นมากอยู่ตรงกลาง และอะตอม 99.99% คือพื้นที่ว่าง!

☀️ โมเดลระบบสุริยะ

• นิวเคลียส = ดวงอาทิตย์ (ประจุบวก หนัก หนาแน่น)
• อิเล็กตรอน = ดาวเคราะห์ วิ่งวนรอบนอก
• ช่องว่าง = อวกาศกว้างใหญ่

🔬 ผลการทดลอง

ยิง α ใส่แผ่นทอง:
• 19,999/20,000 → ผ่านทะลุ (พื้นที่ว่าง)
• 1/20,000 → สะท้อนกลับ (ชนนิวเคลียส!)

ถ้าอิเล็กตรอนวิ่งสะปะสะปะ มันต้องสูญเสียพลังงาน แล้วร่วงลงชนนิวเคลียส → อะตอมพัง! แต่จริงๆ ไม่พัง!

วงโคจรขั้นบันไดของโบร์
Niels Bohr · ค.ศ. 1913 · โคเปนเฮเกน เดนมาร์ก
วงโคจรขั้นบันได — อิเล็กตรอนอยู่เฉพาะระดับแน่นอน

🌈 ทดลอง: สเปกตรัมแสงของไฮโดรเจน

อิเล็กตรอนกระโดดลง → ปล่อยแสงสีเฉพาะตัว!

อิเล็กตรอนอยู่ที่ n=1 (ระดับพื้น)

💡 แนวคิดหลัก

อิเล็กตรอนวิ่งได้เฉพาะบน "วงโคจรพลังงานแน่นอน" (ขั้นบันได) เท่านั้น ห้ามอยู่ระหว่างขั้น!

🌈 การปล่อยแสง

เมื่ออิเล็กตรอนกระโดดลงจากระดับสูงสู่ต่ำ → ปล่อยแสงสีเฉพาะตัว (สเปกตรัม) ขึ้นอยู่กับระยะที่กระโดด

✅ แก้ปัญหารัทเทอร์ฟอร์ด

อิเล็กตรอนในวงโคจรของตัวเองจะไม่สูญเสียพลังงาน → อะตอมจึงเสถียร! (ไม่พัง)

🎯 ระดับพลังงาน n

n=1 (ใกล้นิวเคลียส พลังงานต่ำ)
n=2, 3, 4... (ไกลออกไป พลังงานสูงขึ้น)
กระโดดข้ามขั้น = ดูดหรือคายพลังงาน

กลุ่มหมอก — บอกได้แค่โอกาสพบอิเล็กตรอน

⚛️ หลักความไม่แน่นอน (Uncertainty Principle)

ยิ่งรู้ตำแหน่งชัด → ยิ่งไม่รู้ความเร็ว และในทางกลับกัน!

ความไม่แน่นอนตำแหน่ง Δx
ความไม่แน่นอนความเร็ว Δp

Δx · Δp ≥ ℏ/2

💡 แนวคิดหลัก

หลักความไม่แน่นอน (Uncertainty Principle) ของไฮเซนเบิร์ก: เราไม่มีวันรู้ตำแหน่ง + ความเร็วของอิเล็กตรอนพร้อมกันได้!

☁️ กลุ่มหมอก

อิเล็กตรอนไม่ได้วิ่งเป็นเส้น แต่อยู่เป็น "กลุ่มหมอก" — บอกได้แค่โอกาสที่จะเจออิเล็กตรอนในบริเวณนั้น

✅ แม่นยำที่สุดในปัจจุบัน

อธิบายปรากฏการณ์ทางเคมีและฟิสิกส์ได้แม่นยำที่สุด! ใช้ในการออกแบบ CPU, Laser, MRI และเทคโนโลยีสมัยใหม่

🌊 คลื่น-อนุภาค

อิเล็กตรอนมีสมบัติเป็นทั้งอนุภาคและคลื่นพร้อมกัน! (Wave-particle duality) — แปลกประหลาดกว่าที่คิด
