ใบความรู้

การเท่ากัน a + bi = c + di ก็ต่อเมื่อ a = c และ b = d

การบวก และการลบ บวก/ลบ ส่วนจริงกับส่วนจริง และ ส่วนจินตภาพกับส่วนจินตภาพ (เหมือนรวมพจน์คล้าย)
(a + bi) + (c + di) = (a + c) + (b + d)i  ·  (a + bi) − (c + di) = (a − c) + (b − d)i

การคูณ ไม่ต้องจำสูตร ให้ แจกแจงเหมือนคูณพหุนาม แล้วแทน i² = −1 จากนั้นรวมส่วนจริงกับส่วนจินตภาพ
(a + bi)(c + di) = ac + adi + bci + bdi² = (ac − bd) + (ad + bc)i

ข้อควรระวัง i² = −1 (ไม่ใช่ +1) · เมื่อเจอ i² ให้เปลี่ยนเป็น −1 ทันที · ผลคูณของ (a + bi) กับ (a − bi) จะได้ จำนวนจริง เสมอ
