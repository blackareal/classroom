ทบทวนจากคาบก่อน

หลักการแก้สมการ ทำสิ่งเดียวกันทั้งสองข้างของสมการ เพื่อให้ x อยู่ข้างเดียวโดดๆ โดยใช้การดำเนินการ ตรงข้าม

x + 7 = 12 → ลบ 7 ทั้งสองข้าง → x = 5  ·  4x = −28 → หารด้วย 4 ทั้งสองข้าง → x = −7  ·  3x − 5 = 16 → บวก 5 แล้วหารด้วย 3 → x = 7

วอร์มอัป □ ÷ 3 = 4 ต้องเติมเลขอะไรลงใน □ (ตอบ 12 เพราะ 4 × 3 = 12) วันนี้เราจะใช้ความคิดนี้แก้สมการที่ x ถูกหารอยู่

ใบความรู้

x3 อ่านว่า "x หารด้วย 3" ถ้าเราต้องการให้ x โดดๆ ต้องกำจัดการหารด้วย 3 โดยใช้การดำเนินการตรงข้ามคือ การคูณ

สมการ xa = b คูณทั้งสองข้างด้วย a จะได้ x = a × b

สมการ xa + b = c (หรือ xa − b = c) ทำสองขั้นตามลำดับเดิม: จัดการตัวบวก/ลบ (b) ก่อน แล้วค่อยคูณทั้งสองข้างด้วย a

เทียบกับ ax + b = c ขั้นแรกเหมือนกัน (กำจัด b ก่อน) ต่างกันแค่ขั้นสุดท้าย: ax ใช้ "หาร" ด้วย a แต่ xa ใช้ "คูณ" ด้วย a · เสร็จแล้วต้อง ตรวจคำตอบ ทุกครั้ง

ตัวอย่าง

เขียนวิธีทำทีละบรรทัด และให้เครื่องหมาย = อยู่ตรงกันทุกบรรทัด

แบบฝึกหัด

โจทย์ชุดนี้ตัวเลขเฉพาะของ เปิดกี่ครั้งก็ได้ชุดเดิม · ตอบเป็นค่าของ x (จำนวนเต็ม เช่น 12, −10) · ตอบถูกแล้วระบบบันทึกให้อัตโนมัติ
