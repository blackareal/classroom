ที่มาของ i และจำนวนเชิงซ้อน
ค32202 คณิตศาสตร์เพิ่มเติม 4 · ม.5 · สัปดาห์ที่ 1 (ปรับพื้นฐาน + ปูทาง) ·

ทบทวน

1) รากที่สอง √a คือจำนวนที่ไม่ติดลบ ซึ่งยกกำลังสองแล้วได้ a เช่น √49 = 7 ใช้ได้เมื่อ a ≥ 0 เท่านั้น

2) สมการ x² = k ถ้า k > 0 ได้ x = ±√k (สองคำตอบ) แต่ถ้า k < 0 เช่น x² = −4 ไม่มีจำนวนจริงใดยกกำลังสองแล้วได้ −4

3) ตัวแยกค่า ของ ax² + bx + c = 0 คือ D = b² − 4ac   ถ้า D < 0 สมการไม่มีรากที่เป็นจำนวนจริง วันนี้จะเห็นว่าเราจะ "สร้างจำนวนใหม่" มารองรับสมการเหล่านี้

ใบความรู้

นิยาม ให้ i = √(−1) จึงได้ i² = −1 เรียก i ว่า หน่วยจินตภาพ (imaginary unit)

รากที่สองของจำนวนลบ เมื่อ a > 0:  √(−a) = i√a เช่น √(−49) = 7i,  √(−12) = 2√3 i

การลดรูปราก √(k²·s) = k√s หาตัวประกอบที่เป็นกำลังสองสมบูรณ์ (4, 9, 16, 25, …) แล้วดึงออกนอกราก เช่น √12 = √(4·3) = 2√3,  √18 = 3√2,  √50 = 5√2 ให้ s ไม่มีตัวประกอบที่เป็นกำลังสองสมบูรณ์เหลืออยู่

จำนวนเชิงซ้อน คือจำนวนในรูป a + bi เมื่อ a, b เป็นจำนวนจริง เรียก a ว่า ส่วนจริง (Re) และ b ว่า ส่วนจินตภาพ (Im) เช่น 3 − 5i มี Re = 3, Im = −5 และจำนวนจริงทุกจำนวนคือจำนวนเชิงซ้อนที่ b = 0

การเท่ากัน a + bi = c + di ก็ต่อเมื่อ a = c และ b = d

กำลังของ i วนซ้ำทุก 4 ตัว:  i¹ = i,  i² = −1,  i³ = −i,  i⁴ = 1 แล้ววนใหม่ ดังนั้น iⁿ ให้ดูที่ เศษของ n หารด้วย 4 (เศษ 0 ให้ถือเป็น i⁴ = 1)

ข้อควรระวัง กฎ √a·√b = √(ab) ใช้ได้เมื่อ a, b ≥ 0 เท่านั้น ดังนั้น √(−4)·√(−9) ไม่เท่ากับ √36 = 6 ต้องแปลงเป็น i ก่อน: (2i)(3i) = 6i² = −6

ตัวอย่าง

ตัวอย่างที่ 1 จงหาค่าของ i²³
23 ÷ 4 ได้เศษ 3 ดังนั้น i²³ = i³ = −i

ตัวอย่างที่ 2 จงหาค่าของ √(−3)·√(−12)
√(−3) = i√3 และ √(−12) = 2√3 i
ผลคูณ = (i√3)(2√3 i) = 2·3·i² = 6(−1) = −6
