ทำไมต้องซ่อมฐาน

แคลคูลัสใช้ 3 อย่างนี้ตลอด คือ แทนค่าฟังก์ชัน แยกตัวประกอบ และ อ่านกราฟ ถ้าคล่อง ลิมิตและอนุพันธ์จะง่ายขึ้นมาก ถ้าไม่คล่อง ก็จะติดตั้งแต่ขั้นแรก

ตัวอย่างที่จะเจอเร็ว ๆ นี้ หาลิมิตของ (x² − 4)/(x − 2) เมื่อ x เข้าใกล้ 2 ต้องแยก x² − 4 = (x − 2)(x + 2) ก่อน จึงตัด (x − 2) ได้

ใบความรู้

ค่าของฟังก์ชัน f(a) คือแทน x ด้วย a ในสูตร f(x) บนกราฟคือความสูงของกราฟที่ x = a

แยกตัวประกอบ ดึงตัวร่วมก่อน · x² − a² = (x − a)(x + a) · x² + bx + c หาจำนวนสองจำนวนที่คูณกันได้ c และบวกกันได้ b

จุดตัดแกน จุดตัดแกน y: ให้ x = 0 · จุดตัดแกน x: ให้ y = 0
